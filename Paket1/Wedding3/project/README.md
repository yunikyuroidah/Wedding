## 🚀 Cara Menjalankan Project

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Development Server**
   ```bash
   npm run dev
   ```
   Website akan berjalan di `http://localhost:5173`

3. **Build Production**
   ```bash
   npm run build
   ```

4. **Preview Build**
   ```bash
   npm run preview
   ```
